# Marker vs Skeleton Data Equivalence — Examination Plan

## Question

Do we need `data/raw_markers/` if `data/raw_skeleton/` already contains `Type=Marker` columns?

The JcvPCA pipeline uses skeleton bone quaternions for rotation features and marker CSVs for QC only. This examination validates whether dedicated marker exports are redundant when skeleton exports are available.

## Inputs

| Source | Path | Content |
|---|---|---|
| Marker-only export | `data/raw_markers/` | `Type=Marker` XYZ, units **Meters** |
| Skeleton export | `data/raw_skeleton/` | `Type=Bone` quaternions + `Type=Marker` + `Type=Bone Marker`, units **Millimeters** |

## Sample pairs

Minimum four cases:

1. **252_T1_P1_R1** (user example) — `252_T1_P1_R1_Take 2026-04-28 04.15.00 PM_000.csv`
2. **671_T1_P1_R1** — different participant / marker set (671 vs 252 prefix)
3. **252_T2_P1_R1** — different timepoint, same participant
4. **252_T1_P2_R1** — skeleton-only (no dedicated marker export)

The comparison script auto-discovers all overlapping pairs by filename and reports skeleton-only files separately.

## Checks per pair

1. Header metadata: frame count, length units, rotation type
2. Marker name set equality
3. Presence matrix equality (tracked vs missing frames)
4. Position equality after unit + axis transform (see below)
5. Spot-check named markers at frames 0, 1, 100, 1000, 5000, 10000

## Coordinate transform (skeleton → marker space)

Motive exports use different axis layout and units. Before comparing positions:

```text
marker_X = -skeleton_marker_X / 1000
marker_Y =  skeleton_marker_Z / 1000
marker_Z =  skeleton_marker_Y / 1000
```

## Pass criteria

For every overlapping pair:

- `max_abs_diff < 1e-5` meters (after transform)
- `presence_mismatches == 0`

## Execution

```bash
.venv/bin/python examination/marker_vs_skeleton/compare_marker_sources.py
```

Outputs:

- `comparison_summary.csv` — one row per pair
- `RESULTS.md` — human-readable verdict (generated by script)

Production implementation: `project_io.parse_motive_take()` (skeleton-only pipeline).
